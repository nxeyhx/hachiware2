# 하치와레랑 이야기하기 — 빠른 AI 버전

이 버전은 이전 버전의 문제를 줄이기 위해:
- Qwen2.5 0.5B 빠른 모델 사용
- 답변을 한꺼번에 기다리지 않고 생성되는 대로 화면에 표시
- 답변 길이 제한으로 응답 시간 단축
- 하치와레풍 말투 규칙 강화
- 같은 "조금 더 이야기해줘" 답변 반복 방지
- 브라우저 TTS를 더 밝고 높은 캐릭터 느낌으로 조정
- 음성 입력 유지

중요:
실제 성우의 목소리를 복제한 것이 아니라 브라우저의 한국어 TTS를 캐릭터풍으로 조정한 것입니다.

GitHub Pages에 올린 뒤 첫 실행에서는 모델을 다운로드합니다. 이후에는 브라우저 캐시에 남을 수 있습니다.

Chrome + WebGPU 권장.
